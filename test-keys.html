💡 لإضافة مفتاح جديد:

1. افتح ملف keys.js

2. ابحث عن قسم // 📦 مفاتيح APIs إضافية

3. أضف مفتاحك بهذه الصيغة:

4. استخدمه في أي ملف:

import KEYS from './keys.js';
const myKey = KEYS.myNewKey;
